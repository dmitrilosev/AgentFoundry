# Production iOS App Icon Prompt Template

Fill every bracketed value in English. Keep one central symbol and preserve the constraints.

```text
Use case: logo-brand
Asset type: production iOS app icon, 1024 x 1024 px, 1:1
Primary request: Create a unique, vivid, premium iOS app icon for [PRODUCT NAME], [ONE-SENTENCE PRODUCT PURPOSE], designed for [PRIMARY AUDIENCE].
Central visual metaphor: [ONE SIMPLE, OWNABLE SYMBOL AND HOW IT CONNECTS TO THE PRODUCT]. Use one recognizable central symbol only. Keep it abstract enough to feel original but immediately readable at 40 x 40 px. It must not resemble a letter, product initial, word, generic category cliché, or unrelated logo.
Style/medium: modern premium iOS icon art; friendly, energetic, polished; lightly dimensional with glossy materials, controlled translucent depth, precise highlights, and soft ambient glow.
Composition/framing: one centered oversized symbol with a bold clean silhouette, occupying roughly 68–76% of the canvas; balanced negative space; no secondary objects; edge-to-edge full-bleed square artwork; no pre-drawn rounded corners and no border.
Scene/background: opaque full-bleed [BACKGROUND COLOR STORY] gradient field with subtle depth and a restrained radial glow behind the symbol; no transparent or empty areas.
Color palette: 3–5 harmonious saturated colors — [COLOR 1], [COLOR 2], [COLOR 3], [OPTIONAL COLOR 4], [OPTIONAL COLOR 5] — blended through juicy seamless gradients and expressive color transitions.
Lighting/mood: [BRAND MOOD]; soft studio illumination; subtle inner glow; clean rim light; crisp but gentle specular highlights; refined shadows.
Materials/textures: [GLOSSY MATERIAL DIRECTION]; smooth clean surfaces; subtle volume; no grain, noise, engraving, tiny texture, or excessive reflections.
Constraints: no text, letters, words, app name, numbers, typography, small details, phone, user interface, advertising mockup, frame, watermark, logo badge, transparent background, or pre-rendered rounded-square mask. The image must fully fill the square canvas and remain opaque. Original composition only.
Avoid: multiple symbols; clutter; thin lines; washed-out colors; harsh bloom; cheesy lens flare; metallic chrome overload; stock icon appearance; generic medical cross, heart, shield, chatbot bubble, sparkles, infinity symbol, or other category cliché unless explicitly required by the product brief.
Quality: high
```

If the user supplies a desired symbol, preserve it unless it conflicts with platform constraints. If the first render violates the single-symbol silhouette or resembles a prohibited cliché, change only the metaphor/composition line for the next iteration.
